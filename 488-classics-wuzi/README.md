# 《吳子》入庫：本文の流水線

`/p/wuzi*.html` 四つの讀本と `/img/classics/wuzi-cover.jpg` の製作スクリプト。
覆核と再実行のために残してある。データ（`raw/` `var/` と `*.json`）は入庫しない。

    bash fetch.sh        # 底本＋通校二本＋外字表＋異體字表を取り直す
    bash cover.sh        # 封面（四庫全書本 卷端葉の右半）を裁つ
    bash rebuild.sh      # 全部やり直して四つの頁を書き出す

`opencc-js`（繁→簡）と `sharp`（封面）が要る。どちらもリポジトリの依存では
ないので、`npm install opencc-js sharp` した先を環境変数で渡す：

    OPENCC=/path/to/opencc-js SHARP=/path/to/sharp bash rebuild.sh

## rebuild.sh の順序

| 歩 | スクリプト | すること |
|---|---|---|
| 1 | `assets.py` | 共通の CSS / JS を《司馬法》の頁から取り出す |
| 2 | `parse.py` | 底本（維基文庫標點本）→ `base.json`、六篇四十三段 |
| 3 | `witness.py` | 通校二本を篇ごとに切る → `sbck.json` / `wyg.json`。外字實體を Unicode に還元し、**四庫本が別立てにしている「呉起初見文侯章句」を《圖國》の頭に繼ぐ** |
| 4 | `canon.py` | 標點と字形だけ直す → `canon.json`。**本文の字は一つも改めていない** |
| 5 | `align.py` | 逐字對校 → `variants.json`。書きぶりの對は對校の前に代表の形へ寄せる（さもないと一字の形の差が insert＋delete に割れて二條に數えられる） |
| 6 | `text.py` | `canon.json` → `text.json`。**分段は底本のもので、本頁は一段も切っていない** |
| 7 | `notes_merge.py` `en_merge.py` `ja_merge.py` | `notes/` → `notes.json` / `en.json` / `ja.json` |
| 8 | `to_hans.js` | 繁 → 簡。註釋で「談論」される字形は釘づけ（`notes.json` を読むので 7 の後）。本文には釘を打たない |
| 9 | `build.py` | 四つの頁を書き出す |
| 10 | `meta.py` | 書架カードの題と抄（`*.meta.json`） |
| 11 | `shelf.py` | 書架頁 `/p/dianji.html` に一冊足す（冪等） |
| 12 | `verify.py` | 錨点・id・タグの開閉・段落 id の一致・封面の寸法、それに**本文が底本と逐字同一である**ことを機械検査 |
| 13 | `residue.js` | 繁／簡の取り違えと「自分を取り消す校語」を數える |

`/docs.html` と `docs-manifest.json` は `scripts/build-docs-site.mjs` の
`CLASSICS` に一條足したうえで `npm run gen:docs`。その一條は
`../488-classics-wuzi.patch` にも残してある（`patch -R` で戻せる、確認済み）。

`pvar.py` は註釋を書くときの手控えで、異文を段ごとに割りつけて印字するだけ。
頁には出ない。

## 中身

* `notes/zh1..zh6.py` — 篇旨六・段註四十三（繁體、約一万五千字）
* `notes/colophon.py` — 卷末〈底本與校例〉（繁體）
* `notes/en1..en6.py`、`notes/en_colophon.py` — 英訳（約一万六千五百語）
* `notes/ja1..ja6.py`、`notes/ja_colophon.py` — 日本語訳（約三万字）

## 本子

* 底本：維基文庫《吳子》標點本（圖國・料敵・治兵・論將・應變・勵士の六篇、
  四十三段、本文 4,728 字）
* 通校一：《四部叢刊》本（上海涵芬樓借常熟瞿氏鐵琴銅劍樓藏影宋鈔本印行。
  Kanripo KR3b0004 の SBCK 枝）——今存最古の一支。二卷
* 通校二：《四庫全書》文淵閣本（同 KR3b0004 の WYG 枝）
* 封面：通校二の卷端葉（Wikimedia Commons『文淵閣四庫全書 0726冊.djvu』
  第六二葉、PD-scan）の右半

## この一本で分かったこと（要点だけ）

* **底本は清い。一字も改めていない。**「二本が一致して底本と異なり、かつ
  底本の文が通らない」ところが一つも無かった。手を入れたのは標點（縦組み用の
  冒号「︰」五處）と字形五事だけである。
* **二本が一致して底本と異なる箇所は十處**（字位で十三）。一つ殘らず卷末に
  列擧した。最も差の大きいのは《應變》「行出山外<b>熒</b>之」——二本はともに
  「營之」（陣を張る）に作り、義がまるで違う。
* **四庫全書本は篇次を持たず、《圖國》の前半を「呉起初見文侯章句」という
  別題の一篇に立てている。** 『景印文淵閣四庫全書』第七二六冊第六二葉の
  書影を目驗して確かめた——翻刻の誤りではない。四庫提要は「六篇」と言うので、
  この題は四庫の謄録が卷頭の敘事に與えた標目であろう。本頁は今本に從って六篇。
* **四庫本は「玄」を「𤣥」に作る**（缺筆、清聖祖玄燁の避諱）。
* **翻刻は刻本ではない。** Kanripo の叢刊本翻刻は「二丈四尺」を「二大四尺」に
  作るが、同じ djvu の第一〇八葉（叢刊本《吳子》卷上卷端葉）を目驗すると
  刻本は「丈」である。凡例にこの分際を書いた。
* 底本の「天灶」二處は二本ともに「竈」で、「灶」は簡体字のほうの形——
  《三略》の輪が底本に十七處見つけた「簡繁往復の痕」と同類である。
