先说一个反差。

2026年内，一家做人形机器人的中国公司在上交所敲钟。据公开报道，它开盘遭到数千倍超额认购，首日股价翻了数倍，盘中市值一度冲上高位后又快速回落数十亿美元——一场教科书级的过山车。

同一时期，另一组数字被悄悄压在角落里：MIT NANDA 那份在2025年被反复引用的报告说，约95%的生成式AI试点"未能带来可衡量的营收影响"（注意：这份报告的统计口径后来也有不少争议）；多家机构的CIO调研也显示，真正把智能体部署进生产环境的企业只是少数。

一边是资本市场的估值狂欢，一边是大部分项目"没算出账"。

这就是2026年的AI创业——最不缺的是钱和模型，最缺的是"真能用、还持续付钱"的落地。

今天这篇，我们把2026年最热的7条AI创业赛道，一条一条掰开：为什么热、谁在场上、中国人的机会在哪，以及——哪里在裸泳。

先说清读者定位：这是一篇写给AI从业者、创业者和投资人的硬核盘点。为了照顾非硬核读者，第一次出现的英文缩写我都会用一句大白话解释。

主线：这一年，故事从"造模型"变成了"用模型"#

一句话交代大背景。

2023-2024年是基座大模型的军备竞赛，比的是"谁的模型更强"；2025年是过渡年，主题是"模型即产品"。而2026年，主角彻底换人了——从"谁的模型强"，变成了"模型能干什么活、能收到多少钱"。

标志性事件，是几条陡峭得几乎不真实的收入曲线：

关键信号

  • Anthropic 的 Claude Code，据报道一年内做到了数十亿美元级的年化运行率收入（run-rate=按当前收入水平折算的年化收入）。
  • Cursor（明星AI编程工具），据报道一年出头就把 ARR（Annual Recurring Revenue，年度经常性收入，简单说就是"一年能稳定收到的订阅费"）从约1亿美元推到了二十亿美元级，爬坡速度超过很多SaaS前辈。
  • 法律AI Harvey、客服AI Sierra，也跑出了SaaS史上最快的收入曲线之一。

钱呢？钱还在往基础设施砸天文数字——OpenAI、Anthropic、xAI 这几家头部实验室的估值，都据报道进入了千亿美元乃至更高的量级。但真正定义这一年的，是两条彼此撕裂的张力：

一是"钱砸下去了、价值还没兑现"的巨大鸿沟（就是前面那个95%）；

二是推理成本的雪崩——据近月报道，部分混合大模型的 token 价格已跌入"每百万 token 1美元以下"的区间，降幅陡峭。

这两条张力，一条利好应用层的采用故事，另一条利好应用层、却狠狠碾压重资产的算力商。

记住这个背景，我们开始盘点。

赛道①　AI智能体（Agent）：模型变现的头号出口 🥇#

一句话定性： 不是陪你聊天，是替你干活——2026年模型能力变现的第一出口。

为什么热？ 因为它是前沿模型最清晰的变现路径。Claude Code 证明了：驱动企业收入最快增长的，是"智能体"而不是"对话"。编程、法律、客服这些垂直Agent跑出了真实且高速的ARR，给了VC罕见的"叙事+收入"双击。再加上2026年内，MCP、A2A 这两大智能体互联协议据报道在开源基金会框架下走向整合，让"多个智能体协同"在企业里少了一大障碍——说人话，就是让不同厂家的AI助手开始能"对上话、搭伙干活"。

玩家：

  • 国外： Cognition（旗下 Devin，号称"AI程序员"），据报道以数百亿美元级估值完成新融资，估值在数月内翻倍；Sierra（客服Agent）、Harvey（法律AI），据报道均已跑到数亿美元级ARR。
  • 国内： 智谱 GLM 系列（据其官方基准，在关键Agent任务上已逼近头部闭源模型，且成本低得多——这是厂商自述口径），并上线了 AutoGLM 等桌面智能体；还有蝴蝶效应 Manus。

中国机会： 中国在智能体竞赛里是独立的一极，不是跟随者。突破口在成本和开源——GLM、DeepSeek 这类具备智能体能力的开放权重模型（开放权重=把模型参数公开，开发者可自行部署改造），让开发者能以远低于闭源前沿模型的成本搭Agent。但真正的空白点是深度企业工作流的垂直智能体：目前，还很难看到一个披露ARR能与 Cognition、Harvey 对标的中国玩家。所以机会不在"再做一个通用Agent"，而在把开源模型嵌进法律、财税、客服、供应链这些有真实付费意愿的本土工作流里，先做深一个。

冷水： 现实差距巨大。大部分试点没算出ROI、真部署的是少数，多家机构都警告：相当一部分智能体项目可能因为成本、ROI不清或集成失败被砍掉。几十倍ARR的估值，赌的是"执行零失误+护城河持久"。而同样的模型进步，会让大厂自家Agent反噬垂直玩家——你辛苦筑的护城河，可能只是别人产品里的一个新功能。

一句话金句：智能体的估值定价了"零失误的未来"，可现实里连试点都还在返工。

赛道②　AI基础设施：资本部署的震中 💰#

一句话定性： 这一年资本部署的震中——史上最大的私募融资，撞上正在崩塌的推理单位经济。

为什么热？ 两股相反的力量在这里对撞。一边是史无前例的资本开支和巨额估值；另一边是推理成本的暴跌。智能体和推理模型让每次查询吃掉的 token 激增，所以哪怕单价年年跳水，总算力开支反而还在涨——这让"卖铲子"成了最安全的下注。叠加出口管制造成的中美双轨市场，它成了2026年融资最猛的赛道。

玩家： OpenAI、Anthropic、xAI；neocloud（"新云"，专做AI算力租赁的新型云厂商，区别于传统三大云）里的 CoreWeave、Nebius，据报道营收都在高速增长；芯片侧还有 Cerebras、SambaNova、Groq。中国这边跑的是一套由国家塑形的平行栈：DeepSeek 据报道打破了"不融资"的传统、由国家背景资本领投、以数百亿美元级估值融资，其下一代模型据称同时在英伟达和华为芯片上做过验证；芯片侧则是华为昇腾、寒武纪进入采购清单。

中国机会： 机会在"去CUDA化"的国产推理栈（CUDA是英伟达的软件护城河，"去CUDA化"就是摆脱对它的依赖），以及推理成本战里的极致性价比。国产数据中心的确定性需求，给了本土芯片一块稳定的底盘。短板也清晰——多家智库判断，国产芯片短期内仍难在峰值训练性能上追平英伟达最高端产品。所以中国的位置是：领先于成本与开源，落后于峰值训练。

冷水： 泡沫论已进入主流。"循环融资"（芯片厂给买自家芯片的客户兜底、钱在圈内转）招来了"庞氏"式的类比。AI相关公司在美股大盘里的权重已高到形成系统性敞口。更麻烦的是——token 价格跌破1美元利好应用层，却碾压那些背着巨额折旧和债务的重资产算力商。而真正的硬约束，正从芯片转向电力和电网。核心问题只有一个：那些以万亿计的承诺开支，能不能在钱停之前跑出足够的收入来偿付。

一句话金句：这一轮基础设施赌的不是算力够不够，而是"电够不够、钱停之前收入回不回得来"。

赛道③　具身智能 / 人形机器人：压倒性的中国故事 🤖#

一句话定性： 2026最热的硬件AI主题，而且压倒性地是一个中国故事。

为什么热？ 两股力量汇合。一是 VLA（视觉-语言-动作）基础模型——说白了，就是给机器人装一个"通用大脑"，让它能跨任务、跨形态迁移，把"一台机器只会一件事"变成"一个脑子干多种活"。二是中国制造把物料成本（BOM）打下来、把产量做上去。据行业机构测算，2026上半年全球人形机器人出货约在两万台上下的量级、同比大涨约三倍，其中绝大多数由中国厂商贡献（口径为全尺寸及类人形态，不同机构统计范围略有差异）。

玩家： 宇树 Unitree、智元 Agibot、银河通用 Galbot、优必选 UBTech；国外的 Figure AI、Physical Intelligence、Skild AI。几组信号感受一下：宇树据报道于2026年内在上交所上市，成为中国大陆首家上市的人形机器人公司；智元据报道已下线第一万五千台、并已递表港交所；优必选2026上半年营收据其披露约12.7亿元人民币（同比约翻倍），其中全尺寸人形产品收入激增至约5.9亿元人民币（约合8100万美元，按7.2汇率折算）。

中国机会： 这几乎完全是中国的主场。"具身智能"被写进国家政策，解锁了国家资本、地方政府订单和成本优势供应链。近期真实的商业落地，集中在工厂、物流和训练中心，而不是家庭。开源关键资产（如智元开源了 AgiBot World 数据集与 GO-1 模型）是建立生态引力的打法。机会在供应链、零部件、本体成本工程，以及为真实产线提供拿得出手的自主能力。

冷水： 泡沫信号很明确。据报道已有上百家中国人形机器人公司、本体产能已经跑到需求前面，个别标的上市后暴涨暴跌、估值倍数高到难以自圆其说。绝大多数所谓"部署"，仍是有人盯着的试点、演示编排或遥控操作，VLA 在开放世界的长程操作上依然脆弱。收入相对估值小得可怜（优必选全尺寸人形收入约8000万美元量级，多数美国实验室干脆零收入）。家用需求还没被验证、大量中国需求靠国家资金而非市场自发。IPO狂欢退潮后，大概率是整合，以及一轮"down-round"（融资时估值不升反降的"流血轮"）。

一句话金句：人形机器人卖的是"未来的想象力"，可账本上大多还是"有人在旁边盯着的遥控演示"。

📍 中场休息一下。

如果你已经读累了，记住一件事就够了：上面这四条赛道，热的逻辑各不相同，但冷水几乎是同一盆——估值在给"尚未到来的采用"定价。

智能体、基础设施、人形、编程，市场都在为"以后一定会大规模用起来"买单，而现在真正跑出的、可持续的生产级收入，远比估值暗示的要少。

带着这盆冷水，我们看后面三条。

赛道④　AI编程 / Vibe Coding：最快PMF、最猛变现 ⌨️#

一句话定性： 整个AI栈里，最快达成PMF、变现最狠的应用品类。（PMF=Product-Market Fit，产品被市场验证"真的有人要、愿意持续用"。）

为什么热？ 因为代码这件事可验证、开发者乐意付费、企业看得见直接的ROI。Cursor 据报道一年出头就把 ARR 从约1亿冲到二十亿量级；模型跨过能力阈值后，Agent能完成真实的多文件、多步骤任务（Cognition 曾在官方博客自述，Devin 写了它自己相当高比例的代码——这是自述口径，不必当作精确事实）；"vibe coding"（凭感觉编程：不写代码、用自然语言把想法"说"成软件）又打开了巨大的非开发者市场（TAM=可触达的总市场）。前沿实验室、超大厂和一整墙VC同时涌入。

玩家： Anysphere/Cursor、Cognition/Devin、GitHub Copilot（据报道付费席位已达千万量级）、Lovable、Replit。国内是一场千亿元人民币级的战略战场：字节 Trae 在产品上领先，阿里通义灵码搭配开放权重的 Qwen3-Coder，用每月一美元级起步的定价冲击西方价格体系，智谱 GLM 系列也在编程基准上据其官方数据正面对标头部闭源模型。

中国机会： 中国策略偏好开放模型、激进定价和企业/B2B分发，而不是美式高价SaaS。2026年中，围绕海外编程工具安全性的讨论明显升温，也在客观上加速了国产化替代、开源化、以及"更便宜的 token 经济"这条路线。

冷水： 过热风险很尖锐。头部玩家用几百亿美元估值，背着仅几十亿美元的ARR，隐含极高的前向倍数。这个品类的护城河其实很薄——底层智能来自少数几个基础模型，做IDE/做壳的创业公司面临利润被压缩和平台风险（实验室和超大厂直接下场做编程，还能捆绑、还能低价）。切换成本低，churn（客户流失）是真实威胁。而 vibe coding 让非专家把没审过的代码推上线，本质上是在积累安全与可维护性的债务。中国这边还要再叠加一层地缘碎片化和价格战。

一句话金句：AI编程是变现最快的赛道，也是护城河最薄的赛道——你的壳，可能就是大厂的下一个免费功能。

赛道⑤　垂直行业AI：护城河从模型IP转向工作流与信任 🏛️#

一句话定性： 2026企业软件的破圈故事——护城河从"模型IP"，转向"工作流、数据与信任"。

为什么热？ 前沿模型已经够好了，于是难点从"模型本身"转向了分发、专有数据、集成，以及受监管领域里的工作流与信任。目标垂直（法律、医疗、财税、客服、销售）都是巨大的人力成本池，ROI清晰。收入模式也从"卖席位"转向按结果、按用量计费（比如 Sierra 按成功解决的对话数量收费）。在横向生成式AI试点大面积失败的当下，垂直AI是少数展现出真实企业黏性的品类。

玩家： Harvey（法律，据报道ARR已达数亿美元级、服务律师数以十万计，覆盖大量顶级律所）、OpenEvidence（"医生版ChatGPT"，据报道估值百亿美元级、月度临床咨询量巨大）、Abridge、Sierra、Clay、Rillet。国内医疗是最热的中国垂直：据报道，商汤医疗2026年内完成超1亿美元级融资，估值进入百亿元人民币量级；据艾瑞等机构调研，大量中国医生已在临床中使用AI工具，AI在医院IT预算中的占比也在明显抬升（这些为调研/测算口径，非精确统计）。法律赛道里，智合AI是国内最接近 Harvey 的对标，但体量仍只是其零头。

中国机会： 在受监管、数据密集、有本地合规壁垒的行业里，做那套"记录系统 / 行动系统"。这是资本堆不出来、只有执行力强的团队才建得起来的东西。

冷水： 护城河正在被侵蚀。一个很值得玩味的信号是——据报道，Harvey 公开放弃了自研垂直法律模型，因为前沿通用推理模型在它自家的基准上已经超过了它。这说明很多"垂直"应用本质是薄壳，随时可能被模型实验室或巨头（Salesforce、LexisNexis、微软 Copilot 等）反噬。法律、医疗的监管与责任敞口（幻觉引用、临床差错）是生死线。中国还要再叠一层老问题：变现滞后于炒作、企业付费意愿更弱。

一句话金句：连 Harvey 都放弃自研模型了——垂直AI的护城河，从来不是模型，是数据、集成和信任。

赛道⑥　语音 / AI视频 / 多模态创作：中国全球领先的一条 🎬#

一句话定性： 生成式媒体从"新奇玩具"变成"真金白银"，而中国在AI视频上全球领先。

为什么热？ 三股力量汇合。一是模型质量跨过了"能用于真实工作和娱乐"的阈值（能做到音画同步对白的视频，如 Sora 2、可灵、Veo）；二是变现路径清晰（ElevenLabs、可灵、Suno 等据报道均已跑到数亿美元级ARR）；三是分发飞轮——短视频对廉价视频素材的需求近乎无止境，语音智能体按结果计价，直接替代昂贵的呼叫中心人力。

玩家： 国外有 ElevenLabs、Runway、OpenAI Sora、Suno。国内这条尤其亮眼：快手可灵是全球AI视频收入的领跑者之一（据报道年中ARR达数亿美元级、创作者数以千万计）；MiniMax（稀宇）据报道于2026年内在港交所上市、估值百亿美元级，且相当大比例收入来自海外；生数科技 Vidu 也在冲港股IPO；字节 Seedance 在多项视频基准里名列前茅。

中国机会： 这是中国在生成式AI子领域里，质量和收入双双超越美国在位者最清晰的例证。优势很实在：与快手、抖音这类超级App紧耦合，拿到分发和数据；用激进的开放权重把中国模型铺向全球；再加上强劲的海外消费者变现。这也是中国创业者最有把握"出海"的AI赛道。

冷水： 版权和法律是最大的一把悬顶之剑（Suno、Udio 的诉讼，虽有唱片公司和解带来缓和，但训练数据合法性、欧盟AI法案等仍未定）。Deepfake 和肖像滥用招来监管和平台封禁。更现实的是——视频生成正在快速商品化，大量近乎同质的模型把"每秒素材的价格"一路压向算力成本，利润被挤薄。而基础实验室（OpenAI、谷歌、字节）本身，就直接威胁着 Runway、Pika 这些独立创业公司。

一句话金句：AI视频是中国最有把握出海的一条——前提是熬过版权诉讼，和一场把利润压到贴地的商品化价格战。

赛道⑦　AI消费硬件与AI眼镜：智能手表之后，第一个真PMF的新品类 👓#

一句话定性： AI眼镜，是智能手表以来第一个真正跑出PMF的全新消费硬件品类，而中国是重心。

为什么热？ AI眼镜是2026年的一个拐点。Meta 用带显示的 Ray-Ban 系列验证了需求，Omdia 等机构预测2026年全球出货有望进入千万台级。中国则把它变成了一场全民淘金潮（据报道2025年销量同比大幅增长）。软件侧，智能体正在"吃掉浏览器"（如 Perplexity Comet、ChatGPT Atlas），而少数头部助手已经证明消费者愿意规模化付费——据报道，ChatGPT 的年化收入已达数百亿美元级、付费订阅数以千万计。

玩家： 小米（据报道2026年一季度以约三成份额登顶中国第一）、Rokid（冲港股IPO）、Xreal、Meta；软件侧则有 Perplexity、Character.AI。

中国机会： 中国可以说是2026年AI消费硬件的重心，哪怕它在前沿消费软件上仍落后。优势很纯粹：硬件供应链、价格进攻（百元到数百美元的设备，对打 Meta 数百美元的定价）和速度。机会就在于——把AI做成廉价、能大众普及的物理设备。这，恰恰是中国最擅长的打法。

冷水： 助手巨头（ChatGPT、Gemini、Grok）正把消费AI的需求大口吸走，独立App的经济模型很脆弱。陪伴类产品的监管与安全责任，已经上升到生存级——比如 Character.AI 在一起指控其产品与未成年人自杀有关的诉讼（wrongful death，即"非正常死亡"，案件仍在审理、因果尚未认定）压力下，于2025年11月全面禁止18岁以下用户进行开放式聊天。AI眼镜则是典型的炒作周期：小基数上的高增长、大量同质厂商、薄利、IPO择时亢奋，一旦复购不及预期就可能反转——眼镜大多还是"音频/摄像"的新奇物，缺一个日常刚需的杀手级应用。而 Meta、小米的规模和补贴，让纯玩家很难活。

一句话金句：AI眼镜是中国最擅长的硬件戏，但它还缺一个"每天非用不可"的理由。

普通人 / 小团队，怎么上车？#

七条盘完，你可能更焦虑了：赛道这么挤，巨头全在场，我一个小团队还有戏吗？

有。但要换个姿势。别在最贵的地方硬碰硬，去大厂看不上、堆钱也堆不出来的地方。

  • 别做"下一个通用Agent"，更别再造一个基座大模型。 这是资本和大厂的游戏，据报道已有厂商收缩通用模型投入、转向应用——小团队一头扎进去，多半是送人头。
  • 把开源模型（GLM / DeepSeek / Qwen）当水电用，去啃一条窄工作流。 法律、财税、医疗、供应链——选一个你真正懂、有合规壁垒、有人愿意掏钱的场景，先做深一个，跑出可披露的真实ARR，而不是又一个"没算出账"的试点。
  • 如果你的强项是硬件和供应链，那么具身智能的零部件、AI眼镜的成本工程，是中国最擅长、也最有确定性需求的地方。
  • 如果你想出海，AI视频/多模态是目前中国团队最有把握的一条——质量、成本、分发都站在你这边。
  • 警惕"薄壳"陷阱。 连 Harvey 都放弃自研模型了，你的产品如果只是套一层壳、加个 prompt，就得反问自己：当底层模型再强一档、大厂捆绑进来，我还剩下什么？ 最好的答案是——专有数据、深度集成、和客户的信任。这些是时间和执行堆出来的，不是融资堆出来的。

一句话：在这个人人都盯着几十倍ARR估值的年代，最稀缺的能力，是把一个不性感的场景，做到别人抄不动。

结尾：那个所有人都在装看不见的秘密#

回到开头那个反差——资本市场的估值狂欢，和大部分"没算出账"的试点。

2026年真正稀缺的，从来不是资本，也不是模型能力，而是"可持续的生产级采用"。

而市场的估值，几乎完全定价了尚未到来的采用。当所有人盯着那些天价倍数时，被忽视的恰恰是——今天很多所谓的"ARR"，可能只是实验性试点的收入，一旦企业预算收紧，就会大规模流失。

所以最反共识的判断是这一句：2026年最被高估的，是估值倍数和"智能体万能"的叙事；最被低估的，是分发、专有数据、集成和信任这些"非技术护城河"。

前者是资本能堆出来的泡沫，后者是执行力强的团队才砌得起来的墙。

对中国创业者，这个判断只会更锋利：机会不在模型层的"高举高打"，而在应用层的"脏活累活"；不在对标硅谷的高价SaaS，而在用中国最擅长的成本工程和供应链，把AI变成便宜的物理设备、和能出海的媒体工具。

风口会退，token 会更便宜，估值会回归。到那时候，还站着的，不会是PPT里ARR最高的那个，而是产品被真正用起来的那个。

2026年最热的赛道是什么？表面上，是Agent、是人形、是AI眼镜。

但真正的答案，也许是那句被所有人装看不见的老话——能落地、能收钱、能被信任。
