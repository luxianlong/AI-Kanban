1. 引言：写作背景与问题意识#

《潜规则》成书于世纪之交，吴思以记者与历史编辑的身份，长期浸泡在明清史料——尤其是
《明史》、官员笔记、奏折与判牍——之中。他关心的不是正史里写明的典章制度，而是一个更
朴素、也更尖锐的问题：

为什么白纸黑字的正式规则（王法、律例、圣贤教诲）常常不是真正起作用的规则？在
它们背后，是否存在另一套“不成文、不能明说、却被所有人默认遵守”的规则？

吴思把后者命名为「潜规则」。这个词由本书首创，此后进入汉语日常语汇。全书的方法论
特征是从个案反推通则：他不先立框架再找例证，而是从一桩桩具体的贪贿、陋规、清官
遭遇里，抽象出反复出现的行为模式，再给这些模式起名字（合法伤害权、陋规、血酬……）。

问题意识可概括为三层：

  1. 描述层——真实运转的规则到底是什么？（不是“应该怎样”，而是“实际怎样”）
  2. 机制层——这套潜规则靠什么力量维持自身、并淘汰不合作者？
  3. 代价层——谁为这套系统买单？收益与伤害如何在皇帝、官僚、胥吏、百姓之间分配？

本文档后续各步将分别沿这三层展开。

2. 核心定义：什么是「潜规则」#

潜规则，指在正式规则之外、私下里实际支配着人们行为的不成文规矩。它不见于律条，
却被参与各方心照不宣地遵守；违反潜规则者，往往比违反明规则者受到更迅速、更现实的惩罚。

与正式规则 / 明规则的区别，可以从几个维度对照：

维度正式规则（明规则）潜规则
载体律例、典章、公开的道德教诲不成文、口耳相传、心照不宣
可言说性可公开援引、写进文书不能明说，一旦点破即失效或反噬
权威来源名义上的合法权威（王法、圣旨）实际的利害权力（谁能伤害你、谁能给你好处）
执行力常被架空、选择性执行执行迅速而现实，违者立刻付出代价
功能提供合法性外衣、宣示“应然”分配真实的利益与风险、决定“实然”

吴思的关键洞见是：潜规则并非明规则的“腐败偏离”，而是一套自成体系、可自我维持的秩序。
明规则提供合法性的表皮，潜规则处理利益的实质；两者长期并存，构成“官场的真实游戏”。
正因如此，单纯呼吁“遵守明规则”往往无效——因为真正给参与者发奖惩的是潜规则那一套。

3. 参与者与角色：皇帝—官僚—胥吏—百姓的委托代理链#

潜规则运转在一条层层委托、层层代理的权力链条上。名义上，权力自上而下授予、责任
自下而上负责；实际上，每一层都对上“表演合规”、对下“提取利益”，信息与利害在层与层之间
被不断截留、扭曲。

四类核心角色：

  • 皇帝（最终委托人 / 所有者）——名义上拥有天下，追求江山稳固与赋税充盈，却受制于
    信息不对称：他看不到基层真相，只能通过官僚体系间接治理。
  • 官僚集团（代理人 / 士大夫）——受皇帝委托治理地方，一面向上考绩邀功，一面向下
    经营自己的利益网络；是明规则与潜规则的主要“翻译者”。
  • 胥吏（基层执行者 / 经手人）——不入品级却把持文书、征收、诉讼等具体经办环节，
    是“合法伤害权”最密集的一层，陋规多由此而生。
  • 百姓（最终被代理人 / 买单者）——链条最末端，既是赋税与秩序的名义受益者，又是
    各层提取利益的最终承担者，即所谓“冤大头”。

4. 核心概念术语表#

全书反复出现的几个“发明词”，是理解潜规则机制的钥匙。下表每个先给一句话定义，
后续步骤会对每一条展开机制分析与案例。

术语一句话定义
合法伤害权官吏手中可依据某条规则“合法地”给他人制造麻烦或损害的权力——正因合法，才最好用来敲诈与寻租。
陋规长期沿袭、公开的秘密式的非正式收费与馈送（如常例、部费、火耗），虽无律条依据却被默认为“规矩”。
淘汰清官机制系统会系统性地排挤、边缘化乃至毁掉不肯同流的清廉官员，因为他们威胁到整条食利链的稳定。
身怀利器手握合法伤害权的人“身上带着刀”，即便本无恶意，环境也会诱使其动用权力换取好处——“身怀利器，杀心自起”。
老百姓是冤大头层层提取的成本最终转嫁到最无议价能力的百姓身上，他们为整套潜规则系统买最后的单。
第二等公平在无法得到（明规则许诺的）真正公平时，人们退而求其次、按潜规则行贿以换取“至少不被额外坑害”的相对公道。

术语表在后续步骤中可能增补（如“血酬 / 血酬定律”“潜流”“正式规则的失灵”等相邻概念），
并与逻辑图交叉引用。

5.1 核心机制链：从权力失约到系统自维持#

这是全书的因果主链。链条本身是单向推进的，但真正让它经久不衰的是三条反馈回路
（图中红色虚线）：稳态反哺权力、选择压力清洗队伍、陋规锁定使明规则进一步失灵。正因为
存在这些正反馈，单点整顿（换一个清官、发一道禁令）往往被系统迅速消化。

5.2 角色关系 / 委托代理图：四种流向与结构性缺陷#

沿 皇帝—官僚集团—胥吏—百姓 这条委托代理链，实际流动着四样东西，方向各不相同：

  • 权力 / 暴力（下行）——授权、指派、征收与刑名，越往下越接近合法伤害权的锋刃。
  • 钱财（上行）——赋税与陋规从百姓层层上供、分成、孝敬，真实负担压在最底层。
  • 信息（上行但失真）——真相自下而上传递时被逐层截留、粉饰，形成信息不对称。
  • 庇护（下行）——恩荫、关系网与保护自上而下分配，是维系合作、换取忠诚的黏合剂。

6. 深度分析：机制与案例#

本节把第 5 节的逻辑图“落回地面”。前面几节给的是结构（谁对谁、什么流向哪一层），
这一节要回答的是动力学：在每一个具体故事里，潜规则是怎么从零长出来、又为什么理性人
明知不好却停不下来。分析的统一方法是——先点明涉及角色（对应第 5.2 图的节点），
再拆博弈结构（收益矩阵 / 均衡 / 谁能单方面退出），最后指出它落在第 5.1 主链的哪一环。
贯穿全节的一个判断是：潜规则不是坏人的道德失足，而是给定约束下每个人的最优反应叠加出来的
坏均衡——这也是它比“反腐倡廉”式解释更冷峻的地方。

以下案例与命名（合法伤害权、身怀利器、新官堕落、第二等公平、崇祯死弯）
均出自吴思《潜规则》《血酬定律》相关篇目；三饷（辽饷·剿饷·练饷）、火耗、海瑞、张居正等
属通行明清史常识。本节为机制再分析而非情节复述，博弈论词汇（囚徒困境 / 纳什均衡 /
寻租 / 集体行动困境）是分析工具，非吴思原文用语。成文 2026-07-18。

6.1 合法伤害权与「身怀利器」——寻租的权力基础#

涉及角色：胥吏 / 官僚（持权者）× 百姓或下级（被处置者）。落在第 5.1 主链的 B 环
（官员手握合法伤害权），是整条链的发动机。

吴思的关键发现是：官场食利的真正抓手不是“给好处的权力”，而是“合法地制造损害的权力”。
一名书吏可以照章办事，也可以照章刁难——同一条规则，快办是恩、拖办是罚，从宽是情、从严
是刑，而这一切都在规则允许的裁量区间之内。于是持权者无须违法，只要把裁量的“刻度”握在
手里，就能向对方索价。吴思据此提出「身怀利器，杀心自起」：即便本无恶意，一旦身上带着
这把“合法的刀”，环境也会持续诱使人拔刀——因为不拔白不拔，而拔了几乎没有代价。

博弈结构：这是一个敲竹杠（hold-up）+ 寻租模型。

  • 百姓对某项审批 / 通关 / 结案有刚性需求，且没有替代供给（衙门是独家垄断）。持权者
    因此握有双边垄断下的定价权：他索取的“辛苦费”上限，就是对方为避免被合法伤害愿付的
    全部金额。
  • 关键在于成本与收益的不对称：对持权者，动用伤害权的边际成本≈0（合法、可推诿为“按规矩”），
    边际收益是实打实的陋规；对被处置者，反抗的成本极高（越级、诉讼都要再经过另一批“身怀利器”的人）。
    于是“索取”是持权者的占优策略，“给付”是被处置者的最优反应。
  • 因为收益来自扭曲规则的裁量而非创造价值，它是标准的寻租（rent-seeking）：全社会为
    这套敲诈额外付出交易成本，却没有任何新财富被生产出来——纯粹的净损耗。

这一环是第 5.1 主链能启动的前提：没有不受制约的权力（A），就不会有随处可用的合法伤害权（B）；
而 B 一旦存在，后面的陋规制度化（C）、成本转嫁（D）几乎是逻辑必然。

6.2 陋规与「新官到任」——清官如何被系统同化#

涉及角色：新任官员（初始清廉）× 既有官僚–胥吏共同体（既得利益网）。落在 B→C 的
制度化环节，并直接触发第 5.1 的反馈回路 ②（选择压力）。

陋规（常例、部费、火耗等）之所以顽固，是因为它不是个人贪念，而是一张已经结好的网：
上下同分、人人有份、代代相传。吴思观察到一个近乎规律的现象——新官堕落：一个满怀理想的
新官到任，起初想按明规则办事，却发现自己被结构性地逼到墙角。

博弈结构：这是一个由群体强制执行的协调均衡 + 多人囚徒困境。

  • 拒绝分肥的代价是被孤立乃至被毁掉。陋规是全链条的黏合剂：你不收火耗，下面的胥吏没法
    运转、同僚的分成被打破、上司的孝敬断供——于是整个共同体会把你识别为威胁，用弹劾、
    构陷、架空等手段把你排挤出去。这正是「淘汰清官机制」，对应回路 ②：系统主动筛除
    不合作者，留下的都是合作者，于是伤害权更无制衡。
  • 对新官个人而言，收益矩阵是：独自清廉 → 高道德、但被同化或出局，几乎无法改变系统；
    随俗 → 分享租金、仕途安稳。给定“别人都在收”，随俗是最优反应——这是一个人人
    都被锁死在坏策略上的纳什均衡。
  • 更深一层是多人囚徒困境：如果所有官员都清廉，整体（乃至他们自己长远）会更好；但只要
    存在收益诱惑，单方面清廉者反而受损（承担成本、得不到合作），于是没有人敢先跳出去。
    海瑞式清官之所以成为“奇观”而非常态，恰恰证明了均衡的稳固——他是用极端个人代价对抗
    系统选择压力的反例    ，而系统最终仍能把他边缘化。

6.3 「老百姓是个冤大头」——成本转嫁的终点与集体行动困境#

涉及角色：皇帝 / 官僚 / 胥吏（各层提取者）× 百姓（最末端承担者）。落在第 5.1 的
D 环（成本内部化为百姓负担），并触发回路 ③（规范锁定）。

沿着委托代理链，每一层都在向上表演合规、向下提取利益（第 5.2 图的“钱财↑”与“权力↓”）。
问题是：成本必须有人最终吸收。官僚可以把摊派转给胥吏分担，胥吏可以把火耗转嫁给纳税人，
而百姓下面没有更弱的一层可以再转——他们是这条链的剩余索取者的反面：剩余承担者。
吴思用“冤大头”三字点破：谁最没有议价能力，谁就为整套系统买最后的单。

博弈结构：这是一个“退出无门 + 集体行动困境”的双重锁死。

  • 没有退出选项（exit）。编户齐民、户籍与土地把百姓固定在原地；“用脚投票”离开一个
    辖区，往往只是进入另一批身怀利器者的领地。缺了 Hirschman 意义上的 exit，讨价还价的
    筹码几乎为零。
  • 没有发声能力（voice），源于集体行动困境（奥尔森）：一次摊派的成本分散到千万
    百姓头上，人均不过些许；而抗争的成本（被合法伤害、被治罪）集中且高昂。于是对每个
    百姓，“忍”都是理性的——没有人有激励率先出头，尽管所有人加总起来损失巨大。分散的多数
    斗不过组织化的少数，正是这一环的深层逻辑。
  • 这构成回路 ③：百姓的沉默使陋规被默认为“规矩”，明规则进一步失灵，下一轮提取的门槛
    更低——成本转嫁因此自我锁定。

6.4 「第二等公平」——次优均衡为何稳定#

涉及角色：求办事者（行贿方）× 持权者（受贿方），以及所有旁观并跟进的同类。落在
C 环（潜规则被默认为规矩）的需求侧——它解释了百姓一方为何主动配合潜规则。

如果说 6.1–6.3 讲的是持权者为何索取、系统为何淘汰清官，「第二等公平」回答的是另一半：
被敲诈者为什么不但不反抗，反而主动送礼。吴思的洞见是——当明规则许诺的第一等公平
（真正的秉公办理）实际拿不到时，人们会退而求其次：花钱买一个“至少不被额外坑害”的相对
公道。行贿不是为了占便宜，而是为了赎买本应无偿获得的公正。

博弈结构：这是一个人人行贿的纳什均衡，且是帕累托劣于“无人行贿”的次优点。

  • 给定别人都在送礼，你若不送，就会被针对性地慢办、刁难——即被合法伤害权“点名”。
    于是“送礼”是你的最优反应；一旦所有人都这么想，均衡就是普遍行贿。
  • 它与囚徒困境同构：集体最优是“大家都不送、按明规则办”（第一等公平），但该状态不是
    均衡    ——任何单方面坚持不送的人反而吃亏，任何单方面索贿的持权者反而得利。系统因此被推向
    人人送礼的次优稳态，且没有内生力量能把它拉回第一等公平。
  • “第二等公平”之所以是精妙命名，在于它揭示了潜规则的自愿性外观：受害者主动参与，
    使系统看起来“你情我愿”、几乎道德中性——这正是它极难被“反腐”话语撼动的原因：它不是
    个别坏人的越轨，而是所有理性人共同维护的一个坏均衡。

6.5 「崇祯死弯」——委托代理失灵下，勤政为何加速崩溃#

涉及角色：皇帝（崇祯，最高委托人）× 官僚–胥吏（传导层）× 百姓（承压层）。这是第 5.1
整条主链 + 三条回路在王朝末期的总爆发，尤以回路 ①③ 的正反馈为甚。

「崇祯死弯」是全书最有分量的宏观案例：一个罕见勤政的皇帝，越努力却越快把王朝推下悬崖。
吴思用它证明——当委托代理链本身失灵时，最高委托人的善意与努力会被传导层反向放大成灾难。

机制：一个负反馈本应存在、却被替换成正反馈的死循环。

  • 外患（辽东战事）逼出财政缺口 → 朝廷加征辽饷、剿饷、练饷（“三饷”）。这本是应急，
    但钱要经过官僚–胥吏这条身怀利器的链条才能落地。
  • 传导层借加征之机层层加码（正税一分、附加十分），成本经第 5.2 的“钱财↑”通道，最终
    砸在冤大头百姓头上（D 环）。
  • 百姓破产 → 抛荒、逃亡、投入流民与民变 → 需要更多军费去镇压 → 只能再加征。这就
    接上了回路 ①（稳态/困境反哺权力，迫使皇帝继续加压）与回路 ③（陋规锁定，加派成为新常态），
    形成一个越拉越紧的死弯：每一次“解决问题”的动作都在扩大问题。

博弈结构：委托人努力的“符号反转”+ 负和螺旋。

  • 正常的委托代理里，委托人加大监督/投入应改善结果；但此处传导层的激励与委托人背道而驰
    （第 5.2 的 gap2 激励错配）：皇帝要“救国库”，代理人却把加征当成新的寻租机会。于是
    委托人施加的每一分压力，经过代理层都被翻译成对百姓的更重盘剥——努力的符号被系统反转。
  • 叠加 gap1 信息不对称：崇祯看不到加派在基层被放大成什么样，奏报报喜不报忧（第 5.2
    的“信息↑·失真”），他只能凭失真的信息继续下令，等于蒙眼踩油门。
  • 结果是一个负和螺旋：财富在传导中被大量损耗（寻租净损失），蛋糕越做越小，人人（连皇帝）
    最终都是输家。“死弯”的悲剧性正在于——它不需要一个昏君；一个勤政之君置于失灵的代理
    结构中，其勤政本身就是加速器。这是对“换个好皇帝/好官就能解决”这类单点论的最有力反驳。

6.6 小结：五个案例的共同结构#

把五个案例并置，会看到同一副骨架反复出现——这正是把它们统一映射回第 5 节逻辑图的意义：

案例核心角色潜规则如何形成博弈结构为何理性人集体走向坏结果对应主链环节
合法伤害权 / 身怀利器胥吏·官僚 × 百姓裁量权 → 可合法制造损害 → 索价敲竹杠 / 寻租索取是占优策略，反抗成本过高B（发动机）
陋规 / 新官到任新官 × 官僚共同体分肥网强制入伙，拒者被淘汰协调均衡 + 多人囚徒困境单方面清廉受损，随俗是最优反应B→C，回路②
老百姓是冤大头各层提取者 × 百姓成本层层下转至最弱一环退出无门 + 集体行动困境抗争成本集中、收益分散，忍是理性D，回路③
第二等公平行贿方 × 持权者买不到第一等公平，退而赎买公正人人行贿的纳什均衡不送就被针对，集体最优非均衡C（需求侧）
崇祯死弯皇帝 × 传导层 × 百姓加征经失灵代理层被放大努力符号反转 + 负和螺旋激励错配 + 信息失真，勤政反成加速器全链 + 回路①③

统一的教训有三条：其一，潜规则的基础单元是“合法伤害权”——一切索取都从“我能合法地
让你更糟”开始。其二，它靠正反馈自我维持——淘汰清官、锁定陋规、反哺权力，使系统对
单点整顿免疫（这解释了为何“换个清官”总是失败）。其三，也是最反直觉的一条：坏结果不需要
坏人——给定约束，冤大头忍、求人者送礼、新官随俗、勤政之君加征，每一步都是理性的最优
反应，而这些最优反应叠加出的，恰恰是一个人人受损、却谁也无法单方面退出的坏均衡。这就是
吴思所谓“真实的游戏”——结构性的，而非道德性的。

7. 综合评价：理论内核、边界与现代映射#

前六节做的是由个案抽象出机制。本节反向收束——把《潜规则》从一部“明清官场故事集”
上升为一个可评价、可证伪、可迁移的理论框架：先提炼它的理论内核，再把它放进制度经济学
与寻租理论的谱系里对话，接着划出它的解释边界与被滥用的风险，最后把它的判别工具迁移到
当代组织与治理场景，落成一张可操作的清单。

本节的对话对象——吴思《血酬定律》(2003)、寻租理论(Tullock 1967 /
Krueger 1974)、委托-代理理论(Jensen-Meckling 1976)、诺斯(Douglass North)制度变迁与
《暴力与社会秩序》(2009)——均为通行学术文献；文中的比较与批评是本文档的再分析，
非吴思原文主张。成文 2026-07-18。

7.1 理论内核：一个由两块基石长出的稳定均衡#

把全书的机制压到最简，潜规则可以表述为一个均衡命题：

给定「①不受制约的权力」与「②理性自利的参与者」这两个约束，潜规则是系统几乎必然收敛到的
一个稳定均衡——它靠正反馈自我维持，对单点整顿具有强韧性。

两块基石缺一不可，这正是该理论的判别力所在：

  • 只有①不受约束的权力、却没有②自利算计（假设人人是圣徒），伤害权不会被兑现成陋规——
    但这个假设不现实。
  • 只有②自利、却有①有效的外部约束（独立司法、舆论、可信问责、退出选项），
    合法伤害权会被制衡，索取的边际成本不再≈0，均衡就被打破——这恰恰指出了破解的方向。

因此潜规则不是道德命题而是结构命题：它预测的是“在这组约束下，理性人的最优反应会叠加出
什么”。第 6 节五个案例是同一均衡在不同位置的切片——合法伤害权是基础单元（§6.1），
淘汰清官（§6.2）、成本转嫁（§6.3）、第二等公平（§6.4）是维持机制，崇祯死弯（§6.5）是
均衡在外部冲击下的崩溃形态。全书的冷峻结论——“坏结果不需要坏人”——正是均衡视角的
必然推论：坏的是约束结构，不是参与者的品性。

7.2 理论对话：把潜规则放进谱系里#

潜规则并非孤立发明，它与几条成熟理论同构而各有侧重。看清异同，才能既确认它的洞察、
又避免高估它的原创性。

对话对象核心主张与潜规则的相同与潜规则的不同 / 潜规则的独特处
吴思《血酬定律》暴力集团按“流血的性命”定价，一切合法伤害权最终锚定在暴力上同一作者的下游延伸；血酬为“合法伤害权”提供暴力地基潜规则讲规则层的运行，血酬讲暴力层的定价；前者是表，后者是里，合读才完整
委托-代理理论（Jensen-Meckling / 信息经济学）委托人与代理人目标不一致 + 信息不对称 → 代理成本第 5.2 图的 gap1/gap2 就是标准代理问题；崇祯死弯是代理成本的极端形态主流代理理论找契约/激励设计来收敛；潜规则强调在无外部约束下代理失灵会制度化为稳态，契约本身被潜规则俘获
寻租理论（Tullock 1967, Krueger 1974）人为制造的稀缺（管制、垄断）诱使人竞逐租金，造成社会净损失“合法伤害权→索价”就是寻租；§6.1 明确是 rent-seeking，无新财富、纯净损耗西方寻租多假设规则外生、寻租者游说规则；潜规则里规则的执行者自己制造并出售裁量，寻租内生于执行环节，更隐蔽
诺斯：制度变迁 / 暴力与社会秩序制度是博弈规则；“限制进入的秩序(limited access order)”靠分配租金给精英换取稳定潜规则秩序高度吻合 LAO——用食利链的租金收买官僚集团、换取政权稳定诺斯提供宏观类型学与长时段演化；吴思提供微观机制的显微镜（具体到火耗、陋规、一个新官如何堕落），二者宏微互补

一句话概括谱系定位：潜规则 ≈「执行环节内生的寻租」×「无外部约束下制度化的代理失灵」，
落在诺斯 limited access order 的中国明清切片上，并以血酬定律为暴力地基。 它的原创贡献不在
提出新机制，而在于用极强的画面感与命名，把这些抽象机制在一个具体文明里讲活了——
“合法伤害权”“冤大头”“第二等公平”是传播学上的胜利，让学术概念有了民间穿透力。

7.3 批判与边界：解释力的上限、可证伪性与犬儒风险#

一个诚实的框架必须标出自己的边界。潜规则至少有三处需要警惕：

  1. 解释力的上限——易滑向“万能解释”。 一个理论若能解释一切，往往就什么也没预测。
    潜规则的机制足够普适，以致有被事后套用的诱惑：任何官场弊病都能说成“这就是潜规则”。
    要保持解释力，必须坚持它的判别条件（§7.1 的两块基石）：它只在“权力不受制约 +
    参与者自利”同时成立时预测坏均衡；一旦某地引入了有效制衡而弊病仍在，或制衡缺失却并未
    形成食利链，都是对该理论的反例压力。
  1. 可证伪性偏弱——需要补上“反事实”与“变异”。 吴思的方法是从个案反推通则，长于
    叙事、弱于对照。要让它更像科学而非史观，应追问反事实：同样“权力不受制约”，为什么
    有的时期/衙门陋规轻、有的重？制衡的边际引入（如御史、密折、异地为官、考成法）是否
    带来可观测的差异？§6.5 崇祯死弯给了一个动态反事实（勤政反而加速崩溃），但全书这类
    可检验的对照仍偏少——这是框架从“深刻”走向“可验证”要补的功课。
  1. 最危险的滥用——退化为犬儒主义。 潜规则最大的现实风险不在学理，而在被误读为处世
    哲学    ：“看透了，所以我也照潜规则办”“反正结构如此，清廉是傻”。这是对该理论的根本背叛——
    它是一份结构诊断书，不是行动许可证。吴思揭示“坏结果不需要坏人”，是为了把矛头指向
    约束结构（去建立制衡），而非为个人的同流合污开脱。把“描述性均衡”当成“规范性建议”，
    正是从清醒滑向共谋。阅读潜规则的正确姿势是：用它识别结构病灶，而非用它给自己
    的妥协背书。

小结：潜规则是一把锋利但需上保险的手术刀——它的洞察力来自“不谈道德谈结构”，
而它的风险也恰在这里：抽掉道德主体后，若不接上“改造结构”的行动指向，就会剩下一具
冰冷的犬儒外壳。承认结构决定，是为了改造结构，不是为了取消责任。

7.4 现代映射：从明清官场到当代组织的判别清单#

潜规则的三个核心概念——合法伤害权、陋规、淘汰清官——本质上与朝代无关，它们是任何
「掌握裁量权 + 缺乏有效制衡 + 信息不对称」的组织都会长出的东西。把它迁移到当代场景：

明清概念当代同构现象（示例）
合法伤害权审批/合规/风控/采购/考核岗位的“裁量刁难”：可快可慢、可严可宽的自由裁量被用来寻租或立威
陋规部门间“潜默认”的好处输送、回扣与“惯例”；供应商“公关费”、内部“会来事”的灰色规矩
淘汰清官机制说真话/走正规流程/拒绝同流者被边缘化、穿小鞋、“不合群”，劣币驱逐良币
第二等公平明知该无偿获得的服务/公正，仍需“打点”“找关系”才能正常推进
冤大头成本层层下压到最没有议价权的一环：一线员工、小供应商、终端消费者、纳税人
崇祯死弯高层善意的“整改/加压”被执行层反向放大成基层灾难（层层加码、一刀切、数字造假）

据此可提炼一份「潜规则风险」快速判别清单——用于诊断一个组织/流程是否正在滋生潜规则
（命中越多，风险越高）：

  1. 裁量集中：关键环节是否存在“可合法地让你更糟”的单点裁量权，且无独立复核？
  2. 制衡缺失：受害方有没有低成本的申诉、退出或曝光渠道（voice / exit）？若“投诉要经过
    被投诉者的同一批人”，制衡即形同虚设。
  3. 信息不对称：决策层能否绕过执行层看到基层真相？还是只能依赖被层层过滤的上报？
  4. 激励错配：考核指标奖励的是“对上好看”还是“对下尽责”？二者背离时，gap2 已经出现。
  5. 不成文规矩：是否存在“大家都懂、但不能写进制度、一点破就翻脸”的做法？——这是潜规则
    最直接的指纹。
  6. 对说真话者的待遇：合规者、举报者、走正规流程者是被保护还是被排挤？这是淘汰清官
    机制    是否启动的试金石。
  7. 成本去向：当出问题时，代价最终落在最有权的人还是最没议价权的人头上？

清单的治理含义与 §7.1 的理论内核完全一致：既然潜规则=「不受制约的权力 + 自利参与者」，
那么破解就从打掉“不受制约”入手——给裁量权装上独立制衡、给受害方留出低成本的
voice/exit、把信息通道与激励从执行层手里解耦。这也解释了为什么“换个清官”（只改参与者）
总是失败，而制度性的透明、问责与外部监督（改约束）才可能真正移动均衡。

7.5 全篇结论#

七节走下来，可以把《潜规则》的贡献与限度各归其位：

  • 它讲清了什么——真实起作用的常是明规则背后那套不成文、不能明说、却奖惩分明的
    秩序（§2）；它运行在一条委托代理链上，由合法伤害权这一基础单元驱动（§3、§5、§6.1），
    靠淘汰清官、陋规锁定、成本转嫁三重正反馈自我维持（§5.1、§6.2–6.4），并在崇祯死弯里
    展示了它崩溃时的负和螺旋（§6.5）。
  • 它的理论身位——是「执行环节内生的寻租」与「无约束下制度化的代理失灵」在明清中国的
    显微切片，与血酬定律、寻租理论、委托-代理、诺斯制度变迁同构而各擅其长（§7.2）。
  • 它的边界与戒律——须防止滑成万能解释、须补上可证伪的反事实、尤须警惕被读成犬儒的
    处世哲学    ：它是结构诊断书，不是妥协许可证（§7.3）。
  • 它今天还有用——因为“裁量 + 无制衡 + 信息不对称”长盛不衰，那份判别清单（§7.4）
    可直接用于诊断当代组织与治理。

最后回到全书那句最反直觉、也最有力量的话——坏结果不需要坏人。它既是冷峻的（不能靠
“找个好人”解决），也是有希望的（既然是结构决定的，那么改造结构就能改变结果）。这正是
读《潜规则》应有的落点：不是看破后同流，而是看清后改制。
