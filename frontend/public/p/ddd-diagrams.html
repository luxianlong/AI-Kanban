图版一 · 实线=交接物(文件名即契约),虚线=依赖共享内核,侦查那条虚线是「未共享」

三件事值得单独说,因为它们和「标准 DDD 图」长得不一样,而且都是实测出来的:

上下文之间零代码耦合。全项目 grep 跨上下文 import,结果是 0 —— 每个上下文只 import 自己和共享内核。集成**全部通过文件**:hot.json、 candidates.json、raw/、facts.jsonl、answer.md。 这不是缺陷,是这个系统的真实形态:交接物即契约,而且交接物在磁盘上,冷启动后还在。

防腐层是 SourceAdapter。微博、知乎、谷歌各有各的字段, 适配器把它们归一成 Item,外部模型进不了内部。端口在共享内核,实现在各上下文的 infrastructure/ —— 端口在内、适配器在外。

审阅发现 · 共享内核没共享给最该共享的那个

侦查上下文 import 共享内核的次数是 0。但它恰恰是 facts.jsonl 的生产者 —— 而那份文件是整条分级红线的载体,质量上下文的禁写清单完全建立在它上面。

侦查写事实用的是裸 dict 字面量,不是 Fact 类型。于是**词表漂移没有任何拦截点**。 它已经真的发生了:侦查提示词里写了「倒推的数一律标【推算】」,agent 照做, 内核不认识这个词,两条事实的 grade 静默变成 None。

幸运的是失败方向是安全的(grade=None → 不可引用),但那是运气,不是设计。

差异化这一轴的判据是:换成任何一个通用工具,这件事会不会立刻塌掉。 引语闸门会——没有别的工具会拿成稿里每一处引号去和原件做子串比对。 发布会渲染 HTML 的东西满地都是,所以交付在最下面。

审阅发现 · 核心域投资不足

侦查是差异化最高的子域,但它在代码里有 0 行领域层。 整个系统的教义是「质量来自一手材料的独占性」,而实现这条教义的载体回溯清单 —— 读原文首尾三行、展开每个 URL、跟 301、取平台原生 JSON、拿提交历史、读导航栏目 —— 那 12 条穷举规则**一条都不在代码里**,它们住在技能文档和提示词里。

代码里的侦查只剩 391 行纯基础设施:curl、PDF 抽取、工作流采集。 换句话说,最值钱的那部分领域知识,目前靠 agent 每次自觉照做。 这正是「破例」发生的地方——选题上曾因为规则不在代码里而破例 5 次、5 次颗粒无收, 后来把四道门槛写进 scout.py 才止住。侦查还没走到那一步。

这张图也解释了为什么侦查和交付整体落在基础设施层是诚实的、但不是终点: 交付本来就该是通用域,永远不长领域层没关系;侦查不长,是欠账。

图版三 · 每个类的第一行是构造型;Draft 与四条 Spec 属质量上下文,不在本图

这个聚合只有一条真正的不变式,但它是整个系统里最重要的一行代码:

不变式在哪为什么是它
【网】【传】【假】不得进成稿FactGrade.writable 红线只在这里定义一次。规格只做判断,不重新解释分级。
禁写清单 = 有原话且不可引Dossier.forbidden() 判据是 quotable(分级+禁写双条件),不是 usable_in_draft 单条。
【实·单方】只能写「他说」needs_attribution 核实的是「他说了」,不是「这是真的」。

为什么没有仓储层。持久化就是文件系统,runs/<id>/ 本身就是聚合边界。 加一层 Repository 只会让「卷宗即记忆」这件事更难验证 —— 冷启动后能不能靠目录本身恢复上下文, 是这个系统的硬指标。

为什么没有事件总线。events 是一条 append-only JSONL,没有订阅者、没有重放。 它存在的唯一理由:过规格和发布这两个时刻以前只 print 不落盘, 导致「哪些成稿过了规格却没发」根本答不出来。

本次审阅

四、改了什么,还欠什么

已改:把「分级」和「推导方式」分开。 推算 被当成分级词写进了卷宗,而它根本不是可信度等级 —— 分级问「这条信息可信到什么程度」,推导问「这个数是抄来的还是算出来的」。 两件事正交:一个倒推值完全可以是从【实】原件里算出来的。 现在 Fact 有独立的 derived 字段, parse() 认得那几个推导词并给出说得清的报错,历史写法自动兼容。

欠账影响下一步
侦查不用共享内核,裸 dict 写事实词表漂移无拦截点(已发生一次) 让 harvest_flow 经 Fact 落盘
核心域 0 行领域层载体回溯靠 agent 自觉,会破例 把回溯清单里可判定的部分写成代码
选题门槛已停用但仍在算判定写进 ok/reject 供人工看 按需恢复,不动模型
