段干什么
scout.py批量取候选题的四个数字,硬过滤 + 排序

gate.py三道闸:引语必须是原件子串 / 红线 / 未落盘断言
render.pyblocks.json → 单文件 HTML,图片 base64 内嵌
publish_page.py发公开页,发前强制过闸
harvest_flow.py把工作流产出并进卷宗(横跨各段)

侦查为什么是工作流,不是一个 agent

单 agent 会漏检索模态,而且无法自我证伪。上一轮对抗核查提出 123 处更正,拦下多个致命错误 —— 最典型的是「某人当面骂他是骗子」流传极广,唯一信源竟是被指控者本人的回忆。没有核查,这句一定会被写进稿子。

交接件:卷宗即记忆

两条交付路径

路径怎么走
知乎人工。HTML 出来后复制粘贴,规程见 sop/answer-delivery.md
看板公开页publish_page.py → /p/<slug>.html

知乎那条曾经想自动化:Draft.js 只认真实输入事件,AppleScript 要辅助功能权限且会掉, CDP 要算截图坐标系,插图还得绕 Chrome 的 Private Network Access。三条路各有各的坑, 单次成功率低 —— 所以砍掉了,改出 HTML。

冻结 ≠ 可删。ai_org/quiet_browser.py 被在产的 tools/scout.py:21 import。删掉它,选题侦察一跑就 ImportError,而且是静默断掉。 它是共享基建,不是 legacy —— 清理那个包时唯独绕开它。
