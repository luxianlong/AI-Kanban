域为什么归在这一档
侦查 核心成稿的独占性全部来自这里。那篇全网独一份的稿子,靠的是「发帖 24 分钟后建了 GitHub 仓库」——而那个地址就印在原文最后三行里
质量 核心这一天新增的三个领域模块全在这儿。它拦住的东西是别人写不出来的原因:落点拒答、比喻、自说自话、预告句、一节两件事
选题 支撑门槛是硬的,但门槛本身不产生内容。它的价值是不让 70 分钟的侦查白跑
发现 支撑同上。它找的是缝,不是内容
交付 通用渲染和发布谁都能做。这里唯一值得写的规矩是「图必须有图注」

三聚合图

共享内核在上,质量上下文自己的值对象在下。所有值对象都是只读的。

classDiagram
  class Dossier {
    聚合根
    +Path path
    +facts()
    +forbidden()
  }
  class Fact {
    值对象 frozen
    +claim +grade
    +verbatim +derived
    +usable_in_draft
    +quotable()
  }
  class FactGrade {
    枚举 红线定义处
    实 实·单方 网 传 假
    +writable()
    +needs_attribution()
  }
  class SourceAdapter {
    端口 ABC
    +emit_js()
    +normalize()
  }
  class Draft {
    只读上下文
    +text +blocks
    +quotes +blobs
  }
  class Outline {
    值对象 frozen
    +claim +opponent
    +beams +landing
    +problems()
  }
  class Correction {
    值对象 frozen
    +opening +landing
    +deferral +opponent
  }
  class Block {
    值对象 frozen
    +kind +value +cap
    +is_figure +has_caption
  }
  class Lens {
    值对象 frozen
    +name +asks
  }
  Dossier "1" *-- "0..*" Fact
  Fact --> FactGrade
  SourceAdapter ..> Fact
  Draft --> Dossier
  Draft "1" *-- "0..*" Block
  Draft ..> Correction
  Draft ..> Outline
  Lens ..> Draft
新进来的四个。Outline(动笔前那张纸,四栏、骨架最多八节)、 Correction(落点不许拒答、调查稿开头要有对立面)、 Block(图注这条规格没有它就无处可挂)、 Lens(两个编辑:嫌它长、嫌它闷)。 Draft 不是聚合根,它是规格共享的只读上下文 —— 规格不改它,只返回意见。
