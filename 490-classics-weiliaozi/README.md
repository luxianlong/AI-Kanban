# 《尉繚子》入庫：本文の流水線

`/p/weiliaozi*.html` 四つの讀本と `/img/classics/weiliaozi-cover.jpg` の
製作スクリプト。覆核と再実行のために残してある。
データ（`raw/` `var/` と `*.json`）は入庫しない。

    bash fetch.sh        # 四庫全書本の録文二種・羣書治要・異體字表を取り直す
    bash cover.sh        # 封面（上海圖書館藏白文刊本 卷一卷端葉）を裁つ
    bash rebuild.sh      # 全部やり直して四つの頁を書き出す

`opencc-js`（繁→簡）と `sharp`（封面）が要る。どちらもリポジトリの依存では
ないので、`npm install opencc-js sharp` した先を環境変数で渡す：

    OPENCC=/path/to/opencc-js SHARP=/path/to/sharp bash rebuild.sh

## この一本がほかの六部と違うところ

<b>武經七書のうち、網上に使える標點本が無いのはこの一部だけである。</b>
維基文庫の《尉繚子》標點本は〈伍制令〉〈分塞令〉〈束伍令〉〈經卒令〉の
四篇がまるごと空、〈戰威〉は二百七十七字（篇全體の四割に満たない）、
〈兵令下〉は五十五字しかなく、全部合わせても今本の半分に届かない。
しかも〈天官〉一篇だけは《羣書治要》の文章から起こされていて系統が違う。

だから<b>底本は四庫全書文淵閣本そのものを取り、句讀と段の界は本頁が施した</b>。
`base.py` は毎回の再構築で一事だけを檢べる——
<b>句讀と段の界を取り除けば、本文は四庫本と逐字同一でなければならない</b>。
一字でも違えば止まる（原稿を書いている間に八箇所で實際に止まった。
うち三箇所は「うっかり直してしまった」もので、これが無ければ氣づかなかった）。

## rebuild.sh の順序

| 歩 | スクリプト | すること |
|---|---|---|
| 1 | `assets.py` | 共通の CSS / JS を《六韜》の頁から取り出す（同じ武經七書で、卷 h2 ＋ 篇 h3 ＋ 卷旨・篇旨・逐段註と形がまったく同じ） |
| 2 | `witness.py` | 四庫全書本の録文二種（Kanripo と維基文庫）を篇ごとに切り、突き合わせる → `wyg.json` / `skqs.json` / `witness-diff.json` |
| 3 | `base.py` | `punct/j1..j5.py` の句讀つき本文 → `base.json`。**四庫本と逐字照合** |
| 4 | `canon.py` | **二處だけ改める** → `canon.json`（改字の例は三條すべてを滿たすときだけ。docstring を見よ） |
| 5 | `qszy.py` | 《羣書治要》の抄と逐字對校 → `qszy.json`。**通校本としては扱わない**（別系統だから）——結果は註と卷末に出す |
| 6 | `text.py` | `canon.json` → `text.json`（五卷・二十四篇・百四十段） |
| 7 | `to_hans.js` | 繁 → 簡。**簡體で自分を取り消す三對だけ**（于／於、敎／教、縱／縦）を釘づけ |
| 8 | `notes_merge.py` `en_merge.py` `ja_merge.py` | `notes/` → `notes.json` / `en.json` / `ja.json` |
| 9 | `build.py` | 四つの頁を書き出す |
| 10 | `meta.py` | 書架カードの題と抄（`*.meta.json`） |
| 11 | `shelf.py` | 書架頁 `/p/dianji.html` に一冊足す（冪等） |
| 12 | `verify.py` | 錨点・id・タグの開閉・段落 id の一致・封面の寸法、それに**本文＝四庫本＋句讀＋改字二處**を機械検査 |
| 13 | `residue.js` | 繁／簡の取り違え。**許容表を持つ**——底本は四庫寫本の録文で「于」「内」「黄」「并」の類をそのまま寫しているので、表に無いものだけを赤くする |

`/docs.html` と `docs-manifest.json` は `scripts/build-docs-site.mjs` の
`CLASSICS` に一條足したうえで `npm run gen:docs`。その一條は
`../490-classics-weiliaozi.patch` にも残してある（`patch -R` で戻せる、確認済み）。

`locate.py` は手控え。底本の或る句が上海圖書館本の第何頁の葉に出るかを
見積る（書影の目驗はこれで葉を出した）。頁には出ない。
`pdfjpg.py` は PDF に貼られている頁の JPEG をそのまま取り出す。
`crop.js` `meas.js` `inkscan.js` も手控え——`inkscan.js` は掃描の四十八頁
すべてについて左右半葉の墨の量を測る。**白紙の半葉は卷の變り目の目印**で、
上海圖書館本の卷端葉四つはこれで見つけた。

## 本子

* 底本：《四庫全書》文淵閣本《尉繚子》五卷二十四篇、本文 9,216 字、無句讀。
  録文は互いに獨立な二種——Kanripo KR3b0006 の WYG 枝と維基文庫
  《尉繚子（四庫全書本）》
* 最古の證人：《羣書治要》卷第三十七（唐貞觀五年＝六三一、魏徵ら奉敕撰。
  四部叢刊景上海涵芬樓藏日本尾張刊本）。〈天官〉〈兵談〉〈戰威〉〈兵令〉
  四篇の抄、1,431 字
* 目驗と封面：上海圖書館藏《尉繚子》白文刊本（Wikimedia Commons、PD-scan。
  半葉八行・行二十字、四周單邊）。封面はその卷一卷端葉（560×796）

## この一本で分かったこと（要点だけ）

* **二つの録文の食い違いは零**（9,216 字）。零だけでは獨立の證明にならないが、
  外字として印を付けた字が二家で違う（維基文庫は「揚」「龜」にも印を付け、
  Kanripo は付けない）ので、一方が他方の寫しではない。
* **《羣書治要》は今本とほとんど別の本である。**逐字の共通は〈天官〉五割九分、
  〈兵談〉四割二分、〈戰威〉六割六分、〈兵令〉三割六分。二字以上の差 115 處。
  だから治要の讀みを本文に入れることはしなかった。
* **治要が保存し今本が失ったもの四箇所。**
  そのうち〈戰威〉の一節は、原文が「令」と「事」の二節對舉で、
  兩節の首尾が同文だったために抄手の目が飛んだ——**脱文の痕跡が今も讀み取れる**。
  もう一つ、〈天官〉の「斷紂頭、懸之白旗」は《史記・周本紀》の
  「斬紂頭、縣大白之旗」と合う。今本は「而滅商」の三字に縮んでいる。
* **改字は二處だけ**（形→刑、心→必）。どちらも上海圖書館本の書影で目驗し、
  治要も支持する。**そのうち一つは封面の第三行に見えている。**
* **提要の「其書坊行本無卷數」は事實に合わない。**上海圖書館藏の坊刻白文本は
  「尉繚子卷一」「卷二」「卷第三」「卷四」「卷五」を刻し、各卷が新しい葉から
  始まる（四箇所とも書影で目驗）。しかも**その五卷は四庫の五卷と分け方が違う**
  ——刊本の卷二は〈攻權第五〉から、卷三は〈原官第十〉から。各一篇ずつずれる。
  卷四・卷五の界は一致する。
* **提要の「漢志雜家有尉繚三十九篇」は「二十九篇」の誤り。**
  今本《漢書·藝文志》雜家は「尉繚子二十九篇」、兵形勢家に別に「尉繚三十一篇」。
* **刊本は善本ではない。**〈制談〉「一夫仗劒擊于市」を「一武伏劒擊於市」に作り、
  一句のうちに形近の誤りが二つある。だからその異讀は一概には從わない。

## 中身

* `punct/j1..j5.py` — 四庫本の本文に句讀を施したもの（五卷・二十四篇・百四十段）
* `notes/zh1..zh5.py` — 卷旨五・篇旨二十四・段註百四十（繁體、約二万二千字）
* `notes/colophon.py` — 卷末〈底本與校例〉（繁體、十三段）
* `notes/en1..en5.py`、`notes/en_colophon.py` — 英訳（約二万語、全百四十段）
* `notes/ja1..ja5.py`、`notes/ja_colophon.py` — 日本語訳（約三万二千字、全百四十段）
