# 大明王朝·衙门经营：一个知县的六年（模拟经营网页游戏）

这是《潜规则》系列的**收官续作**——一款以「潜规则」为主题的**模拟经营**网页游戏。你执掌清河县六年，逐年调度四条杠杆，在**上意、民心、清誉、库银、私囊**之间求存。和本系列的[抉择版游戏](./daming-wangchao.md)不同：那是一局一局的两难抉择，这一款让你**像经营者一样管理一整套衙门财政**——看着账本上每一笔钱的去向，亲手推动那台"不需要坏人也能自我运转"的机器。

> **来源与时效**：玩法与文案基于吴思《潜规则：中国历史中的真实游戏》(2001) 的分析框架，与本系列的[学术版分析](./qianguize-wusi.md)、[好玩版](./qianguize-haowanban.md)、[抉择版游戏](./daming-wangchao.md)同源。游戏为纯前端、单文件、无后端存档，开箱即玩；本页最后更新于 2026-07。

## 这是一款什么样的游戏

一款**数值经营 × 官场生存**的模拟游戏。你不是一次次做单选题，而是**逐年经营一套没有俸禄能养活的衙门财政**：钱从哪来、送往何处、留下多少，全凭你调度。你有五项资源：

| 资源 | 含义 | 触底/失衡会怎样 |
| --- | --- | --- |
| 🎏 **上意** | 府道对你的欢心、考成 | 归零即**革职查办**，游戏结束 |
| 🧑‍🌾 **民心** | 治下百姓的承受度 | 归零即**民变四起**，你当替罪羊 |
| ⚖️ **清誉** | 清廉声望 / 你的良心 | 不直接致命，但决定**结局走向** |
| 🏛️ **库银** | 官库存银，须逐年解足**上供** | 亏空累积过深即**案发下狱** |
| 💰 **私囊** | 你的家当 | 既是"赢面"，也是填亏空的软肋 |

## 核心玩法：逐年调度四条杠杆

每一年，你先设定四条杠杆（各 4 档），**账本会实时预估**这一年的收支与民情，再"开征结算"过完这一年：

| 杠杆 | 你在经营什么 | 对应的潜规则 |
| --- | --- | --- |
| 🔥 **火耗加征** | 正税之外的附加，越高私囊越丰、民心越薄 | 火耗、层层加派 |
| 🧾 **差役征比** | 多雇书吏差役征收更足额，但他们要吃陋规、也更扰民 | 合法伤害权 / 身怀利器 |
| 🎁 **孝敬上宪** | 炭敬冰敬送往府道，用**私囊**买上意 | 陋规 |
| 🌾 **惠民之政** | 修水利、办义仓，用**库银**买民心与清誉 | 淘汰清官机制的反面 |

结算之间还会插入**年中随机事件**（命案投状、上宪考察、水旱成灾、同僚约分、挂号钱、漕粮短纳），每个选项都对应一条机制，选完弹出「🔎 潜规则解读」，把你刚做的经营决策翻译成书里的术语。

**难点设计**：上供额度**逐年上涨**，第 4 年起朝廷加派**三饷**——这正是"崇祯死弯"。越到后期，你越会发现：账面达标就得压榨民心，惠民养望就得开罪上宪。**每一步都是当下的最优解，相加却是一个谁都无法独自退出的坏均衡。**

## 八种下场，八面镜子

任满六年、京察过关即为胜，但"胜"有很多种脸：

- **同流合污·加官进爵**（系统的赢家：私囊丰、上意足）
- **异数·循吏全身而退**（极罕见：既保清誉又活到任满——像海瑞那样"证明规则的例外"）
- **爱民罢官**（把银子花给百姓、省了孝敬 → 被系统当"不合群"筛出去：淘汰清官机制的实现）
- **酷吏搜刮·官声狼藉**（靠榨取活下来，代价是一县元气）
- **碌碌太平官**（不功不过，安然退场——大多数人在潜规则里的活法）

以及三种任内翻车：**革职查办**（上意归零）、**民变四起**（民心归零）、**亏空案发·锒铛下狱**（累计亏空压垮）。

结局屏会告诉你：**这一局你究竟亲历了哪几条潜规则**、五项资源的最终账面，以及通往深度分析的入口。
