# 大明王朝：潜规则生存模拟（网页游戏）

这是《潜规则》系列的第 6 步、也是收官之作：把前五步梳理出的六大机制，**做成一款可以真正玩的网页游戏**。你扮演崇祯元年放了外任的一位**知县**，在约 11 个抉择里争取「任满全身而退」——保住乌纱、填平亏空、别激起民变。至于要不要守住良心，是你的选择；而系统会用它的方式，回答这个选择的代价。

> **来源与时效**：玩法与文案基于吴思《潜规则：中国历史中的真实游戏》(2001) 的分析框架，与本系列的[学术版分析](./qianguize-wusi.md)、[好玩版](./qianguize-haowanban.md)同源。游戏为纯前端、单文件、无后端存档，开箱即玩；本页最后更新于 2026-07。

## 这是一款什么样的游戏

一款**文字抉择 × 数值经营**的官场生存模拟。你有四项状态：

| 状态 | 含义 | 归零/触底会怎样 |
| --- | --- | --- |
| 🎏 **乌纱** | 仕途稳固度、上意 | 归零即**罢官/下狱**，游戏结束 |
| 🧑‍🌾 **民心** | 治下百姓的承受度 | 归零即**民变四起**，你被当替罪羊 |
| ⚖️ **清誉** | 清廉声望 / 你的良心 | 不直接致命，但决定你的**结局走向** |
| 💰 **白银** | 家财 / 库银 | 亏空过深即**案发下狱** |

每一回合抛给你一个真实的官场两难——征钱粮、放灾赈、审人命、应付上宪考察、朝廷加派三饷……**每个选项都对应《潜规则》里的一条机制**，选完会弹出一段「🔎 潜规则解读」，把你刚做的事翻译成书里的术语。

游戏刻意设计成：**当清官很难活，随大流最省事**——这正是全书的论点。你会亲身体会到「劣币驱逐良币」不是道德口号，而是一步步理性选择叠出来的结构性结果。

## 六大机制，如何被做进玩法

| 书中机制 | 在游戏里的样子 |
| --- | --- |
| **合法伤害权 / 身怀利器** | 一桩人命官司，你的判笔可救人可杀人——收厚礼判给出价高者，还是秉公退礼得罪权贵？ |
| **陋规** | 拜印第一天就有「常例」清单：炭敬、冰敬、印结银。交，你就入了伙；不交，你上了同僚的「另册」。 |
| **淘汰清官机制** | 拒收分肥、据实考成、整顿胥吏——每一次「守规矩」都在扣你的乌纱。系统主动把清官筛出去。 |
| **老百姓是个冤大头** | 赈灾克扣、火耗加征、层层发包，成本一路转嫁，终点永远是那个跑不掉的百姓。 |
| **第二等公平** | 百姓交「挂号钱」只求「至少别再多坑我」；你随大流收费——一个人人吃亏却谁都不敢先退出的均衡。 |
| **崇祯死弯** | 收官回合朝廷加派三饷：如数严逼→民变，抗命请命→丢官。越勤政催逼，链条末端崩得越快。 |

## 十种下场，十面镜子

游戏有约 **10 个结局**，每个都是一面照见系统的镜子——从**「清官罢黜」**（淘汰清官机制的实现）、**「民变四起」**（崇祯死弯崩断）、**「亏空案发」**（击鼓传花接到最后一棒），到**「同流合污·步步高升」**（第二等公平的系统赢家）、以及罕见的**「异数·全身而退的清官」**（像海瑞那样「证明规则的例外」）。

结局屏会告诉你：**这一局你究竟亲历了哪几条潜规则**，并给出通往深度分析的入口。
