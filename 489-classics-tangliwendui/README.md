# 《唐李問對》入庫：本文の流水線

`/p/tangliwendui*.html` 四つの讀本と `/img/classics/tangliwendui-cover.jpg` の
製作スクリプト。覆核と再実行のために残してある。
データ（`raw/` `var/` と `*.json`）は入庫しない。

    bash fetch.sh        # 底本＋四庫全書本の録文二種＋異體字表を取り直す
    bash cover.sh        # 封面（上海圖書館藏刊本 卷上卷端葉）を裁つ
    bash rebuild.sh      # 全部やり直して四つの頁を書き出す

`opencc-js`（繁→簡）と `sharp`（封面）が要る。どちらもリポジトリの依存では
ないので、`npm install opencc-js sharp` した先を環境変数で渡す：

    OPENCC=/path/to/opencc-js SHARP=/path/to/sharp bash rebuild.sh

## rebuild.sh の順序

| 歩 | スクリプト | すること |
|---|---|---|
| 1 | `assets.py` | 共通の CSS / JS を《三略》の頁から取り出す（同じ武經七書で、卷しか無く、卷旨と逐段註を持つ——本書といちばん近い） |
| 2 | `parse.py` | 底本（維基文庫標點本）→ `base.json`、三卷・五十問對・百九十七段 |
| 3 | `witness.py` | 四庫全書本を卷ごとに切る → `wyg.json` / `skqs.json`。**互いに獨立な二つの録文**（Kanripo と維基文庫）を突き合わせて録文の誤りを洗い、**四庫本の分卷が今本と違う**ので今本の卷立てに切り直す |
| 4 | `canon.py` | **十二處だけ改める** → `canon.json`。改字の例は三條すべてを滿たすときだけ（本文冒頭の docstring を見よ） |
| 5 | `align.py` | 逐字對校 → `variants.json`。書きぶりの對は對校の前に代表の形へ寄せる（さもないと一字の形の差が insert＋delete に割れて二條に數えられる） |
| 6 | `text.py` | `canon.json` → `text.json`。**段の界も問答の界も底本のもの** |
| 7 | `notes_merge.py` `en_merge.py` `ja_merge.py` | `notes/` → `notes.json` / `en.json` / `ja.json` |
| 8 | `to_hans.js` | 繁 → 簡。**本文の「陳」四十八處のうち四十三處は「阵」に落とす**（陣の意味だから。殘る五處は四庫本が「陳」のままにしている所と同じ）。註釋で談論される字形は釘づけ |
| 9 | `build.py` | 四つの頁を書き出す |
| 10 | `meta.py` | 書架カードの題と抄（`*.meta.json`） |
| 11 | `shelf.py` | 書架頁 `/p/dianji.html` に一冊足す（冪等） |
| 12 | `verify.py` | 錨点・id・タグの開閉・段落 id の一致・封面の寸法、それに**本文が底本＋十二處の改字と逐字同一である**ことを機械検査 |
| 13 | `residue.js` | 繁／簡の取り違えと「自分を取り消す校語」を數える |

`/docs.html` と `docs-manifest.json` は `scripts/build-docs-site.mjs` の
`CLASSICS` に一條足したうえで `npm run gen:docs`。その一條は
`../489-classics-tangliwendui.patch` にも残してある（`patch -R` で戻せる、確認済み）。

`locate.py` と `pvar.py` は手控え。前者は底本の或る句が上海圖書館本の
第何頁の葉に出るかを見積る（書影の目驗はこれで葉を出した）。
後者は異文を段ごとに割りつけて印字するだけ。どちらも頁には出ない。
`pdfjpg.py` は PDF に貼られている頁の JPEG をそのまま取り出す
（Commons の PDF 縮小圖は一二八〇幅で頭打ちになるため）。

## 本子

* 底本：維基文庫《唐李問對》標點本（卷上・卷中・卷下、五十問對、
  一百九十七段、本文 10,292 字）
* 通校：《四庫全書》文淵閣本《李衛公問對》三卷。録文は互いに獨立な二種——
  Kanripo KR3b0010 の WYG 枝と維基文庫《李衛公問對（四庫全書本）》
* 目驗：上海圖書館藏《唐太宗李衞公問對三卷》白文刊本
  （Wikimedia Commons、PD-scan。半葉八行・行二十字）。四庫の系統に屬さず
  註解も無い、獨立した第三の證人。封面もこの本の卷上卷端葉
* 封面：同上（PDF 第一頁、1652×1211 の JPEG を裁って 560×790）

## この一本で分かったこと（要点だけ）

* **四庫本の分卷は傳世諸本と違う。** 四庫の卷上は今本より 831 字、
  卷中は 854 字はやく終わる。提要みずから「世所行本不分卷數、今依文獻通考
  定爲三卷」と言うので、この分け方は館臣が立てたもの。
  **ただし「世所行本不分卷數」という言い分そのものが當たらない**——
  上海圖書館本は卷をはっきり分けており、卷末題の立つ所は今本と同じである
  （二箇所とも書影で目驗した）。
* **底本を改めたのは十二處**、いずれも上海圖書館本の書影で一字ずつ確かめた。
  そのうち「馬隆<b>討</b>涼州」は封面の第七行に見えている。
* **書影があったおかげで改めずに済んだ所がある。** 卷下が《司馬法》を引く
  「天下雖<b>平</b>、忘戰必危」は、《司馬法》の原文も四庫本も「安」に作るが、
  上海圖書館本は底本と同じく「平」。改めたのは館臣であって、この書ではない。
  同類が七處あり、刊本はことごとく底本の側に立った。
* **二つの録文の食い違いは四處だけ**、うち三つは字形、一つが本當の誤り
  （四庫寫本の「𠕂」を Kanripo が「冄」と讀んでいる）。
* 底本と四庫本の**異文は 103 條・107 字位**。字形と通用の異は別に 527 處
  （四庫本は清聖祖玄燁の諱を避けて「玄」を通篇「𤣥」の缺筆に作る）。
* 本書が引く《漢書·藝文志》太公《謀》八十一篇・《言》七十一篇・
  《兵》八十五篇の數は、漢志と**完全に一致する**——僞書論の是非には
  立ち入らないが、これは誰でも檢べられる事實なので卷末に記した。

## 中身

* `notes/zh1..zh3.py` — 卷旨三・段註百九十七（繁體、約一万三千六百字）
* `notes/colophon.py` — 卷末〈底本與校例〉（繁體）
* `notes/en1..en3.py`、`notes/en_colophon.py` — 英訳（約一万二千八百語、全段）
* `notes/ja1..ja3.py`、`notes/ja_colophon.py` — 日本語訳（約二万五千字、全段）
