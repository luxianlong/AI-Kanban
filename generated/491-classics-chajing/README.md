# 《茶經》入庫：本文の流水線

`/p/chajing*.html` 四つの讀本と `/img/classics/chajing-cover.jpg` の
製作スクリプト。覆核と再実行のために残してある。
データ（`raw/` `var/` と `*.json`）は入庫しない。

    bash fetch.sh        # 底本と四庫全書本の録文二種を取り直す
    bash cover.sh        # 封面（明刊『百川學海』本 卷上卷端葉）を裁つ
    bash rebuild.sh      # 全部やり直して四つの頁を書き出す

`opencc-js`（繁→簡）と `sharp`（封面）が要る。どちらもリポジトリの依存では
ないので、`npm install opencc-js sharp` した先を環境変数で渡す：

    OPENCC=/path/to/opencc-js SHARP=/path/to/sharp bash rebuild.sh

## 本子

* **底本**：維基文庫『茶經』三卷十篇の標點本。『四庫』が據った浙江鮑士恭家藏本の
  系統。陸羽自注を含めて本文七千餘字、百二十四段。
* **通校本一**：『四庫全書』文淵閣本。録文は互いに獨立な二種——
  Kanripo KR3i0019 の WYG 枝と維基文庫『茶經（四庫全書本）』。
  **七千百十六字を逐字で突き合わせて食い違い零。**
* **通校本二（目驗）**：國立國會圖書館藏 明刊『百川學海』壬集『茶經』三卷
  （請求記號 特1-2229、Wikimedia Commons、PD-scan）。
  『百川學海』は宋咸淳の左圭の輯で、今存『茶經』の最古の一支はこの叢書を通る。
  **網上に録文が無いので、書影を一葉ずつ呼び出して目驗した。**
  封面はその卷上の卷端葉（560×714）。

## rebuild.sh の順序

| 歩 | スクリプト | すること |
|---|---|---|
| 1 | `assets.py` | 共通の CSS / JS を《六韜》の頁から取り出す |
| 2 | `witness.py` | 四庫本の錄文二種を篇ごとに切って突き合わせる（→ 零） |
| 3 | `base.py` | 底本の wiki を篇・段・陸羽自注に分ける |
| 4 | `canon.py` | 句讀の正規化・字形の統一十八對・**改字十六處** |
| 5 | `collate.py` | 底本 × 四庫本 の逐字對校（異文 139 條・197 字位） |
| 6 | `text.py` | 三卷・十篇・百二十四段に組む |
| 7 | `to_hans.js` | 繁 → 簡。字形を談論している對は釘づけ |
| 8 | `notes_merge.py` `en_merge.py` `ja_merge.py` | `notes/` → 三つの json |
| 9 | `build.py` | 四つの頁を書き出す。陸羽自注は `.zhu`、器の名は `.qm` |
| 10 | `meta.py` `shelf.py` | 書架カードと書架頁（冪等） |
| 11 | `verify.py` | 錨点・id・タグ・段落 id・封面の寸法、それに**本文 ＝ 底本 ＋ 正規化 ＋ 改字十六處** |
| 12 | `residue.js` | 繁／簡の取り違え。**申告表を持つ**——「于」「云」「里」「斗」の類は底本の形 |

`/docs.html` と `docs-manifest.json` は `scripts/build-docs-site.mjs` の
`CLASSICS` に一條足したうえで `npm run gen:docs`。その一條は
`../491-classics-chajing.patch` にも残してある。

## この一本で分かったこと（要点だけ）

* **四庫本は「聖唐滅胡明年鑄」を「聖唐年號某年鑄」に差し替えている。**
  〈四之器〉風爐の三足の第三句。録文二種ともそうなので録文の誤りではない。
  百川本の當該葉を目驗したが、「唐」の下は一字だけで刻が漫漶しており、
  何の字とも定めがたい。三本の異を卷末に具錄した。
* **底本は〈八之出〉湖州の一節十九字を脱している。**
  「生山桑、儒師二寺、白茅山懸腳嶺，與襄州、荊南、義陽郡同」。
  百川本が明刻し、四庫本にも形を變えて殘る。湖州は陸羽がこの書を書いた土地で、
  顧渚山は後の唐代第一の貢茶山——**全書で地理上いちばん重い一條が、
  底本のいちばん缺けた一條だった。**
* **百川本は自分で「〇某當作某」式の校語を持ち、底本はそれを呑み込んでいる。**
  〈二之具〉「三亞者」に「〇亞當作椏」、〈六之飲〉「荊俞」に「〇俞當作渝」。
  底本の本文は徑ちに「三椏」「荊渝」に作る。校語の痕跡は殘っていない。
* **篇題は四庫本だけが違う。** 四庫本は「一茶之源」「二茶之具」「四茶之噐」、
  底本と百川本は「一之源」「二之具」「四之器」。封面の葉にその三字が見える。
  卷中の器目（二十四器の目錄）も四庫本だけが持つ。
* **四庫本は善本ではない。** 「輕身換骨」→「換膏」、「黃山君」→「責山君」、
  「臨蒸縣」→「臨遂縣」、蒯通を缺字にする等。獨立した證人として扱うだけで、
  これに據って改字はしない。十六處の改字はすべて百川本が同じ側に立つ。
* **底本に簡體の形が一つ紛れている。** 〈九之略〉の「鹾簋」（〈四之器〉の條目名は
  「鹺簋」）。#486『三略』の輪で見つかった「簡繁回轉の痕跡」と同類。
* **NDL 藏本は綴じ違いが一葉ある。** 卷首の「茶經序」（皮日休『茶中雜詠序』）が
  卷上第一葉と第二葉のあいだに綴じ込まれている。

## 中身

* `notes/zh1..zh3.py` — 卷旨三・篇旨十・**段ごとの白話譯**百二十四（繁體、約一万六千字）
  ——#495 で「語釋」から「譯文」に書き換えた。各段は**まず本文の白話譯**
  （陸羽自注も〔 〕のまま譯す）、そのあと丸括弧に字句の注と校記を置く。
* `notes/colophon.py` — 卷末〈底本與校例〉（繁體、十六段）
* `notes/en1..en3.py`、`notes/en_colophon.py` — 英訳（約一万二千語、全百二十四段）
* `notes/ja1..ja3.py`、`notes/ja_colophon.py` — 日本語訳（約二万二千字、全百二十四段）
* `pdfjpg.py` — PDF に貼られている頁の JPEG をそのまま取り出す
* `inkscan.js` — 見開きの左右半葉の版匡を輝度走査で見つける（封面の裁ち寸法はこれで出した）
